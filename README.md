# CareFlow: Clinical Pathway Process Mining

## Project Overview

CareFlow is a Data Analytics project designed to study patient journeys through clinical activities. It will use process mining and data analysis to explore patient pathways, activity durations, process delays, and potential bottlenecks.

## Project Objectives

- Identify common clinical pathways from healthcare event-log data.
- Analyze the time spent on clinical activities.
- Identify potential process bottlenecks and unusual pathways.
- Visualize important findings using charts and a dashboard.
- Document the methodology, results, and limitations.

## Planned Workflow

1. Select a suitable public healthcare dataset.
2. Understand the dataset structure and data quality.
3. Identify and handle missing or invalid values.
4. Perform exploratory data analysis.
5. Apply process-mining techniques.
6. Analyze pathways, durations, and potential bottlenecks.
7. Develop visualizations and a dashboard.
8. Prepare project documentation and final reports.

## Technology

Python and suitable data analytics, visualization, and process-mining libraries will be selected during development.

## Project Status

Initial setup. Dataset selection, analysis, process mining, and dashboard development are pending.

## Data Privacy

Only public or otherwise authorized datasets will be used. Sensitive patient information, credentials, and secrets must not be committed to the repository.
